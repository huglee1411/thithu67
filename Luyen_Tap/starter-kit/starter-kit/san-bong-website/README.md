# GreenField – Đặt **sân bóng** _mini_.

Website **đặt sân** _bóng đá mini_.

## Thư mục dự án

| Thư mục   |   Nội dung |
| --- | --- |
| docs | tài liệu bàn giao |
| data | bảng tính đặt sân |
| logs | log truy cập website |

## Danh sách file dự án

```
Get-ChildItem -Path .

```
